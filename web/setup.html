欢迎使用爱思办公任务看板

这个向导帮你在 3 分钟内完成所有基础服务配置。全程免费、无需企业资质，也不会用到任何第三方的账号。

  • 任务看板及配置地址推送（推荐）：公网隧道不定时失效、地址重建后会变化，届时自动把新地址发到你邮箱
  • 公网隧道（推荐）：手机不在家也能访问看板（Cloudflare 免费隧道）
  • 邮件告警：任务出现异常/等待确认时即时收提醒邮件，也可定时收任务汇总
📋 你只需要准备：一个常用邮箱（QQ / 163 / Gmail 均可）。 我们会引导你在邮箱设置里生成一个「SMTP 授权码」——它不是邮箱密码， 只用于本服务发通知邮件给你自己，随时可以在邮箱设置里撤销。
🔒 隐私说明：所有配置保存在你本机 config.json，不会上传到任何服务器； 配置向导页面也只允许在这台电脑上打开（外部访问会被拒绝）。

📖 怎么获取授权码？（1 分钟）
QQ 邮箱：网页版 → 设置 → 账号 → 「POP3/IMAP/SMTP…服务」→ 开启「SMTP 服务」→ 按提示发短信 → 生成 16 位授权码
163 / 126：网页版 → 设置 → POP3/SMTP/IMAP → 开启「IMAP/SMTP 服务」→ 弹窗里设置「授权码」
Gmail：需开启两步验证后，在 Google 账号「应用专用密码」生成 16 位密码

隧道方式
ℹ️ 快速隧道说明：
• 地址每次重启都会变，但没关系——新地址会自动推送到你配置的邮箱
• 想要永久不变的地址？切换到「固定域名（正式）」
🚀 命名隧道（Cloudflare 官方，免费，地址永久固定）：
1. 需要一个已托管到 Cloudflare 的域名（如 dpdns.org 免费子域名，NS 已指向 Cloudflare）
2. 创建 API 令牌：dash.cloudflare.com → 右上角头像 → 我的个人资料 → API 令牌 → 创建令牌，权限选：账户 · Cloudflare Tunnel · 编辑 和 区域 · DNS · 编辑
3. 填下方三项点「初始化」——自动创建隧道、绑定域名 CNAME、切换到固定地址

任务告警与汇总

先在手机看板详情页用「🔔 追踪」标记要监控的任务，再在这里开启定时汇总。

报警邮件标题 = 该前缀 + 任务名称。需同时满足：任务在手机端「🔔 追踪」标记 + 上方「单任务报警」总开关打开。
