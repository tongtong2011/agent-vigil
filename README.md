# AgentVigil

> **Keep a vigil over every agent, in every harness.**
> 移动看板 + 邮件告警，盯住你所有 AI Agent 的任务。

**AgentVigil** is a mobile **task board** and **email alert** system for your **AI agents** — watch agent tasks **across every harness** from one board and one inbox. 通过电脑端 Node.js 桥接服务，在手机浏览器（PWA）中查看电脑上 AI Agent 的任务列表与任务内容（与电脑端一致的对聊天式视图），并可在手机上**直接给 AI 任务发消息**（确认、纠偏、补充要求）。任务**异常 / 待确认**立即邮件告警，**定时汇总**也走邮件，配对信息变动自动推送——人不在电脑旁也能掌控任务。

- 📱 **Mobile task board**：PWA 一套代码覆盖 Android / iOS / 鸿蒙，无需上架
- 📧 **One email inbox**：告警、汇总、配对信息，全部进一个邮箱
- 🔌 **Not a plugin**：独立桥接服务，不改 Agent 工具本身；V4 起以**插件化适配器**接入多个 harness——当前内置：爱思办公（ACP）/ WorkBuddy / Trae
- 🌐 **公网访问**：Cloudflare 免费隧道（免账号免域名）+ 配对二维码 + 手机远程配置

> **免责声明**：本项目为个人学习研究用途的互操作工具，与爱思办公官方无关。
> 实现依赖非官方接口，可能随时失效；请仅使用自己的账号、自己的邮箱等外部服务配置。
> 官方若推出手机版，本项目即完成使命。

## 支持的 Harness

| Harness | 接入方式 | 状态 |
| --- | --- | --- |
| 爱思办公（Agnes Office，ACP 本地后端 agnesd） | ACP 协议（自动发现端口 + 进程内存读密钥），可发消息 | ✅ V1 起基线 |
| WorkBuddy | 本地转录 JSONL 直读（进程门禁），V4.1 起可发消息（headless CLI 续聊） | ✅ V4.0 接入 |
| Trae（Trae CN） | 记忆子系统转录 JSONL 直读（主数据库加密不可读，无指令注入通道 → 只读） | ✅ V4.1 接入 |
| 其他 Agent 工具 | 实现 `lib/adapters/base.js` 的 BaseAdapter 接口即可接入 | 🔜 欢迎 issue 提需求 |

AgentVigil 按 **harness 无关**设计：桥接服务与看板/邮件链路不绑定任何一家工具，新 harness 只需新增一个数据源适配器（`lib/adapters/`，注册于 `lib/adapters/index.js`）。

## 功能

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| FR1 | 连接配对 | 电脑端展示二维码（地址 + 配对码，码在有效期内可重复使用），手机扫码或手动输入完成配对，下次自动连接 |
| FR2 | 任务列表 | 按创建时间倒序展示标题 / 状态（进行中·已完成·失败）/ 时间，支持下拉刷新 |
| FR3 | 任务详情（对话视图） | 与电脑端一致：用户消息右气泡、AI 回复左气泡（Markdown 渲染：表格 / 加粗 / 代码块），底部模型名与时间 |
| FR4 | 处理过程折叠 | 每条 AI 回复下方的工具调用折叠为「已处理 N 步」胶囊，默认收起；含失败步骤时红色提示 |
| FR5 | 实时刷新 | WebSocket 事件驱动（任务有变化才拉取）+ 8 秒兜底轮询；断线指数退避重连；内容无变化不重渲染 |
| FR6 | 手机发消息（V2） | 详情页底部输入栏，任务报错或等待确认时直接回复「同意执行」「改用方案 B」等；限速保护 |
| FR7 | 公网访问（V2） | 自动拉起 Cloudflare 免费隧道（免账号免域名），手机任何网络可访问；断线自动重连 |
| FR8 | 配对信息推送（V2） | 配对码/公网地址有变动时，自动把地址+配对码+二维码**推送到你的邮箱**（邮件带服务器发送时间与「第 N 次生成」计数，与页面/控制台对应；失败自动重试）（企业微信可选） |
| FR9 | 配置向导（V2） | 首次启动分步引导配置邮箱/隧道/配对策略，保存立即生效（仅限本机访问） |
| FR10 | 手机远程配置（V2） | 推送邮件带第二个区块（链接+二维码）：手机扫码可**改收件邮箱 / 切换发件配置档案 / 发测试邮件**（令牌鉴权，敏感操作仍限本机向导） |
| FR11 | 发件配置自动故障转移（V2） | 保存 ≥2 份发件档案时，当前 SMTP 连续 2 次发送失败自动切换下一份并立即重试——多套配置指向同一收件箱，哪套活着推送都能送达 |
| FR12 | 任务两级分组（V2） | 首页按任务工作目录显示为「文件夹 → 任务」两级（与电脑端一致）：默认只显示文件夹，逐个点开或顶栏「全部展开/收起」 |
| FR13 | 任务告警与定时统计（V3） | 详情页「🔔 追踪」标记要监控的任务（存手机本地，重开保持）；「单任务报警」总开关/标题前缀与「任务汇总」总开关/间隔/标题均在配置中心配置 → 被追踪任务出现异常或待确认（阻塞）且报警总开关打开时立即发单任务提醒邮件；按间隔把被追踪任务汇总成表格邮件；邮件复用现有发件服务与收件人 |
| FR14 | 多渠道统一看板（V4） | 列表页顶置渠道 Tab（健康状态点，绿在线/红故障），点击切换各 harness 的任务列表；仅接入一个渠道时不显示 Tab、界面零变化；服务端快照预热 + 前端按渠道缓存，进看板/切 Tab 毫秒级秒显；列表条数上限可配（默认 100，滑块最高 1000，`listLimitMax` 可继续调大） |
| FR15 | 渠道级配置 + Tab 式配置中心（V4） | 渠道启停用复选框勾选（勾上才出现该渠道配置块）；「任务汇总/单任务报警开关、标题前缀」按渠道独立配，「汇总间隔、汇总标题、看板列表条数上限」全渠道统一配；配置页重构为 6 页签（首页总览/邮箱推送/公网访问/公共配置/渠道独立配置/看板与配对），每页独立保存即时生效 |
| FR16 | 多渠道邮件合并与来源标注（V4） | 各渠道汇总合并为**一封**邮件、按渠道分节（渠道 → 任务目录 → 任务三级定位，绝不缺失）；单任务报警邮件标注「来源渠道」；停用渠道自动隔离（不出节、不报警）；旧 config.json 自动迁移，无需手工改 |

数据**恒来自各 harness 的本地真实数据**（爱思办公 ACP 后端 / WorkBuddy 与 Trae 的本地转录文件直读），没有演示/假数据机制——某渠道数据源不可用时该渠道看板为空，并在启动日志、推送邮件、手机看板顶部三处醒目提示，恢复后自动跟上（爱思办公启动后无需重启桥接；WorkBuddy/Trae 有进程门禁，应用关闭即清空看板、重开自动恢复）。

## 为什么选它

- **对比远程桌面**：远程桌面给你"完整电脑"，但手机操作痛苦、流量大、还要自己解决内网穿透。AgentVigil 只给你"任务状态 + 告警 + 回复"这条最窄也最高频的路径，手机浏览器即用。
- **对比自己写轮询脚本**：不用写一行代码，配对/隧道/推送/故障转移/告警去重都已处理好；部署者用自己的邮箱与账号，无订阅、无第三方中转。
- **对比通用 CI/IM 通知**：CI 通知面向流水线结果；AgentVigil 面向**对话式 AI 任务的中间态**——"等你确认"这类阻塞会实时告警，并且你能在手机上直接把确认发回去。

## 当前状态（如实）

- 当前版本 **V4.1**（开发期），核心链路（看板/告警/隧道/推送）稳定可用；逐次改动见 [CHANGELOG.md](CHANGELOG.md)。
- **多渠道已落地（V4 插件化适配器）**：爱思办公（ACP）、WorkBuddy（本地转录直读 + V4.1 起可发消息）、Trae（本地转录直读，只读）——渠道启停、按渠道告警/汇总、合并邮件分节均已实现。
- Roadmap：接入更多 Agent 工具（谁需要谁提 issue）；Trae 渠道发消息通道待评估。
- 告警边界说明：覆盖"任务异常 / 待确认 / 定时汇总"；"模型 token 或积分耗尽"目前作为阻塞态的一种成因被间接覆盖（告警邮件会提示排查积分），**没有**独立的配额专项告警；Trae 渠道摘要记录无执行状态字段，仅 running/done 两态、不触发即时告警（汇总正常参与）。

## 启动前置条件（务必先读）

> ⚠️ **看板的数据来自各渠道对应的本地 Agent 工具**——至少要有**一个**已接入的 Agent 工具在运行，看板才有数据；都没运行就是空看板，不会显示任何演示假数据。

| # | 前置条件 | 说明 |
| --- | --- | --- |
| 1 | **Node.js ≥ 18**（建议 LTS） | https://nodejs.org 下载安装，一路下一步 |
| 2 | **想看的渠道对应的电脑端工具在运行** | 爱思办公：桌面端登录并保持运行（自动发现 agnesd 端口与密钥）；WorkBuddy：桌面端运行（本地转录直读 + 进程门禁）；Trae：IDE 使用中（读记忆子系统转录） |
| 3 | **联网** | 首次 `npm install` 装依赖；cloudflared 未安装时首次启动自动从 Cloudflare 官方下载（约 18MB，放入项目 `tools/`） |
| 4 | 手机端无需安装任何 App | 浏览器打开即用（可选「添加到主屏幕」变 PWA） |

**未满足前置条件时的行为**（服务照常启动，绝不崩溃）：

- 启动日志：醒目警告框「⚠ 未检测到爱思办公（agnesd）本地服务……请先启动爱思办公桌面应用」（各渠道有对应提示）
- 推送邮件：合并汇总邮件内附加红色「数据源不可用」警告节，并附配置中心 `http://127.0.0.1:8787/setup.html` 链接（该页仅限电脑端打开）
- 手机看板：对应渠道 Tab 顶部置顶提示条「未检测到 XX 进程，取不到任务数据」，工具启动后自动消失

### 部署启动（3 步）

1. **下载解压**：GitHub Releases 下载 `agent-vigil-VX.Y.Z.zip`（或 `git clone` 本仓库），解压到任意目录
2. **双击 `启动服务.bat`**：首次运行自动安装依赖（需联网，约 1~2 分钟），之后自动启动桥接服务；习惯命令行的话也可 `npm install` 后 `node bridge.js`
3. **完成配置中心**：按控制台提示打开 `http://127.0.0.1:8787/setup.html`（仅限本机电脑），6 页签 Tab 式配置中心：

```
首页（状态总览 + 连接手机二维码）→ 邮箱推送（选服务商 → 填授权码 → 发测试邮件；可存档案）
→ 公网访问（自动检测，免注册；支持命名隧道固定域名）→ 公共配置（汇总间隔 + 汇总标题）
→ 渠道独立配置（渠道勾选启停 + 各渠道汇总/报警开关与前缀）→ 看板与配对（配对码有效期 + 列表条数上限）
```

每个页签底部独立保存、保存即生效。配置完成后，连接信息（地址 + 配对码 + 二维码）会自动发一封邮件到你邮箱，以后有变动也会自动重推。

### 手机连接

1. 打开电脑端控制台显示的**地址**，或用手机扫描二维码 / 打开推送邮件里的链接（配置推送后，人在外面也能收到新地址新码）。
2. 手机与电脑同一 WiFi 时用局域网地址即可；配好隧道后用公网地址，任何网络可用。
3. 输入 6 位配对码 → 连接成功后进入任务列表。
4. （可选）通过浏览器菜单「添加到主屏幕」安装为 PWA 应用。

桥接服务重启后设备配对会失效，需重新扫码/输入配对码（安全设计：配对码只存内存）；
已配置邮箱推送时，新配对码会自动发到你邮箱，不用跑回电脑旁看。

### 日常使用注意

- **电脑保持开机**：桥接服务窗口、爱思办公电脑端都要开着（关闭黑窗口 = 停止服务）
- **电脑休眠/断网** 手机就连不上——建议在电源设置里把「睡眠」改为「从不」（或接电源时永不休眠）
- 爱思办公重启没关系：桥接会自动重新发现它的端口与密钥；桥接服务重启才需要重新配对

各邮箱 SMTP 授权码获取路径、服务器端口、发件档案与故障转移、非标服务商（如 2925.com）处理，见 **[docs/邮箱推送配置.md](docs/邮箱推送配置.md)**。

## 接口

`GET /health`（健康检查，含 `channels` 各渠道在线汇总）、`GET /api/tasks?channel=`（任务列表，缺省 agnes）、`GET /api/tasks/:id?channel=`（任务详情）、`POST /api/tasks/:id/messages`（发消息，V2；只读渠道如 Trae 返回 501），均需请求头 `X-Device-Token`（配对成功时返回，手机端自动携带）。
配置中心接口 `GET/POST /api/setup/*` **仅允许本机 127.0.0.1 访问**（远程一律 403）。


## 常见问题（精选）

- **看板是空的**：99% 是对应的 Agent 工具没在运行——启动对应工具（爱思办公/WorkBuddy/Trae），桥接自动重连出数据（无需重启）。
- **提示配对码无效**：配对码过期（默认 15 分钟）；过期后 60 秒内自动发新码（已配置推送时直接进邮箱）。
- **提示配对已失效**：桥接重启会清空设备令牌（只存内存），重新扫码即可。
- **手机界面是旧版**：下拉刷新 1~2 次（Service Worker 后台自动更新）。

完整 FAQ（含命名隧道三段排查法、收不到邮件排查、告警不触发三要素）见 **[docs/常见问题.md](docs/常见问题.md)**。

## 安全与合规

- **默认只读**：对爱思办公仅做读取，WorkBuddy/Trae 适配器只读本地转录文件；唯一的写操作是手机发消息（agnes 走 `session/prompt`、WorkBuddy 走 headless CLI 续聊，均须配对令牌 + 限速 + 可关闭；Trae 只读无此通道），不创建任务、不删除任何东西。
- agnesd 密钥只存在于电脑端内存；手机端仅持有桥接配对签发的设备令牌。
- 配对码在有效期内可重复使用（多设备可先后配对）、到期自动换新推送，有效期可配（5~120 分钟）；配对接口限速防爆破；发消息接口限速。
- 公网隧道流量经 Cloudflare 加密中转；**配置中心仅限本机 127.0.0.1 访问**，SMTP 授权码等凭据永不回传前端、只存本机 `config.json`。
- 所有外部服务（邮箱/企业微信/隧道）均使用部署者自己的账号，项目本身不内嵌任何第三方账号，不经任何第三方服务器中转。
- 中性命名、不打包官方素材；以 MIT 许可开源（见各设计文档的合规策略）。
