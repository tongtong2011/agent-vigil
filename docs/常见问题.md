# 常见问题（FAQ）

> 适用版本：V3.x · 与源码及 CHANGELOG 核对（2026-10-11）

## 连接与数据

- **看板是空的**：99% 是爱思办公没在运行——看板顶部有橙色提示条时，回电脑启动爱思办公桌面端即可，桥接 15 秒内自动连上并出数据（无需重启）；若刚部署还没配，先在电脑端打开 `http://127.0.0.1:8787/setup.html` 完成向导。
- **看板空白但无提示条**：数据真为空——电脑端爱思办公里还没有任务/会话。
- **手机打不开地址**：同一 WiFi 用局域网地址（Windows 首次运行需在防火墙放行 Node.js）；不同网络用公网隧道地址（向导里开启）。
- **提示配对码无效**：配对码过期（默认 15 分钟）；服务会在过期后 60 秒内自动发新码（已配置推送时直接进邮箱），也可重启服务立即获取。
- **提示配对已失效**：桥接服务重启会清空设备令牌（安全设计：令牌只存内存），重新扫码配对即可（新码已推送到邮箱）。
- **爱思办公重启后**：桥接自动重连——agnesd 重启会换端口和密钥，自动发现机制会重新获取（连续失败 ≥3 次触发重新发现）。
- **进行中任务的延迟**：AI 正在执行时手机端约 3~5 秒刷新一次；顶栏显示「轮询中」= WebSocket 暂不可用已自动降级，恢复后切回「实时」。
- **离线**：展示最后缓存的任务列表。
- **电脑端任务偶发标红「被锁」**：手机查看详情需向爱思办公本地后端加载一次会话，偶发红点属正常，电脑端点开该任务即恢复（详见 CHANGELOG V1 变动二）。

## 隧道与公网访问

- **公网地址打不开**：快速隧道地址随重启变化，以最新推送/控制台为准；Cloudflare 偶发首次建连慢，重试即可。
- **固定域名（命名隧道）配置完打不开**：公网链路共三段，按报错逐段排查——
  1. **域名解析不出（浏览器提示 DNS 错误）**：Cloudflare 上缺 CNAME 记录。到 DNS 面板加：类型 `CNAME`、名称 `@`（或你的子域）、目标 `<隧道ID>.cfargotunnel.com`（隧道 ID 在 Tunnels 页面可见）、**代理状态打开（橙色云）**。
  2. **报 503**：流量已进隧道但没有路由规则（ingress）。到 [one.dash.cloudflare.com](https://one.dash.cloudflare.com) → Networks → Tunnels → 点你的隧道 → **Public Hostname** → Add a public hostname：Domain 选你的域名，Service 类型选 **HTTP**、URL 填 `localhost:8787`。这是手工配置最容易漏的一步——**只建隧道+加 CNAME 不够，没有 Public Hostname 必定 503**。
  3. **本机服务没起**：电脑上执行 `curl http://127.0.0.1:8787/health`，不返回 ok 就是桥接没在跑。
- **推荐做法**：直接用配置向导第 3 步「固定域名（正式）」的**初始化按钮**——自检式幂等：同名隧道已存在就复用、CNAME 缺失/指向不对自动补、路由规则缺失自动写；手工弄了一半也没关系，点一次收敛到正确状态。
- **初始化报错对照**：`Authentication error` / `获取隧道运行令牌失败` = API 令牌权限不足（需「账户 · Cloudflare Tunnel · 编辑」+「区域 · DNS · 编辑」）；`未在该账号找到 zone` = 域名未托管到该 Cloudflare 账号或 NS 还没生效（最长数小时）；`unknown variant` = 旧版本代码，更新重试。
- **API 令牌创建**：dash.cloudflare.com → 右上角头像 → 我的个人资料 → API 令牌 → 创建令牌（自定义令牌，按上面权限勾选）；令牌只在初始化时用一次，不保存。
- **想完全手工配置命名隧道**：Zero Trust 仪表盘建隧道（Networks → Tunnels → Create a tunnel）→ Public Hostname 绑域名和 `localhost:8787`（会自动建 CNAME 和路由规则）→ 把运行令牌填进本机 `config.json` 的 `tunnel.tunnelToken`，并设 `tunnel.mode: "named"`、`tunnel.hostname: 你的域名`，重启桥接。
- **cloudflared 下载失败**：网络被拦截 → 手动下载 Windows 版放入项目 `tools/`：https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe

## 推送与告警

- **收不到推送邮件**：①先在向导里点「发送测试邮件」排查（多数是授权码填错或端口不对）；②检查手机邮件 App 的垃圾邮件箱；③确认邮件 App 开了通知。更多见 [docs/邮箱推送配置.md](邮箱推送配置.md)。
- **收不到告警邮件**：确认三件事同时成立——「单任务报警」总开关已开（向导第 4 步）+ 该任务已点「🔔 追踪」+ 任务确实进入异常/待确认状态（同一阻塞态只发一次，恢复后再次阻塞才会再报）。
- **发消息提示失败/无回复**：消息送达即返回成功，AI 处理需要时间（复杂任务数分钟），回复实时出现在对话流；限速（每分钟 10 条）会提示 429，稍等即可。

## 其他

- **手机界面是旧版**：下拉刷新 1~2 次即可（Service Worker 后台自动更新，仅首次需要）。
- **电脑休眠后手机连不上**：电脑休眠/断网手机就连不上——建议电源设置里把「睡眠」改为「从不」（或接电源时永不休眠）。
