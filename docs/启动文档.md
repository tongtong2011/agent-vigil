# 启动文档（新用户务必先读）

> 最后更新：2026-10-11 · 适用版本：V3.x 及以上

## 一句话须知

**本项目内置的数据源是「爱思办公」电脑端。** 爱思办公在运行 → 看板有真实任务数据；
爱思办公没运行 → **看板为空**（绝不显示任何演示/假数据），并在三个地方醒目提醒你。

> V4 规划：数据源以**插件形式**接入，可内置/支持更多 agent 工具（如其他 Coding Agent 等）。
> 当前版本固定绑定爱思办公。

## 启动前置条件

| # | 条件 | 说明 |
| --- | --- | --- |
| 1 | **Node.js ≥ 18**（建议 LTS） | https://nodejs.org 下载安装，一路下一步 |
| 2 | **爱思办公电脑端**：已安装、已登录、**保持运行** | 任务数据实时读取它的本地 AI 后端 `agnesd`（端口与密钥自动发现）。**这是数据的唯一来源，没它就没数据** |
| 3 | **联网**（首次） | 首次启动自动 `npm install`；`cloudflared` 未安装时自动从 Cloudflare 官方下载（约 18MB，存入项目 `tools/`，仅一次） |
| 4 | 手机端 | 无需安装任何 App，浏览器打开即用 |

## 快速开始（3 步）

1. **下载解压**：GitHub Releases 下载 `爱思办公手机协同端-VX.Y.Z.zip`（或 `git clone` 本仓库）。
2. **双击 `启动服务.bat`**（保持黑色控制台窗口开着——关了就是停服务）。首次运行自动装依赖，随后启动桥接服务并显示地址 + 配对码。
3. **完成配置向导**：在**电脑**浏览器打开控制台提示的 `http://127.0.0.1:8787/setup.html`（仅限本机），5 步配好邮箱推送 / 公网隧道 / 任务告警。保存即生效，连接信息自动推送一份到你邮箱。

手机端：打开邮件里的链接（或扫控制台二维码）→ 输入配对码 → 进入看板。

## 爱思办公没启动时会怎样？（行为约定）

服务**照常启动、绝不崩溃**，但取不到任务数据，此时：

1. **电脑启动日志**：醒目警告框
   `⚠ 未检测到爱思办公（agnesd）本地服务……请先启动爱思办公桌面应用（内置 AI 后端 agnesd），桥接服务会自动发现并连接，无需重启。`
2. **推送邮件**：附加橙色「⚠ 前置条件提醒」区块，说明看板暂无数据，并附配置向导链接
   `http://127.0.0.1:8787/setup.html`（该页是本机页面，**只能在电脑端打开**，手机点开无效）。
3. **手机看板**：列表顶部置顶橙色提示条「⚠ 未检测到爱思办公进程，取不到任务数据……」。

**恢复方式**：在电脑上启动爱思办公桌面端即可——桥接每 15 秒自动重试发现连接，**无需重启桥接服务**；连上后手机提示条自动消失、数据自动出现。

## 常见「没数据 / 连不上」排查清单

| 现象 | 排查 |
| --- | --- |
| 看板空白 + 手机顶部提示条 | 爱思办公没开 → 电脑启动爱思办公，等 ≤15 秒自动恢复 |
| 看板空白 + 无提示条 | 数据真为空：电脑端爱思办公里还没有任务/会话 |
| 手机打不开地址 | 同一 WiFi 用局域网地址（防火墙放行 Node.js）；外网用隧道地址；或用邮件里最新链接 |
| 隧道未就绪 / 想固定域名 | 向导第 3 步：快速隧道免注册；固定域名用「初始化命名隧道」按钮（幂等自检，弄一半也能收敛） |
| 收不到推送邮件 | 向导「发送测试邮件」排查授权码/端口；查垃圾箱；详见 README「邮箱推送配置指引」 |
| 提示配对码无效 | 配对码过期/已用；新码已自动推送邮箱，重启服务也会立刻出新码 |
| 手机界面是旧版 | 下拉刷新 1~2 次（Service Worker 后台自动更新） |
| cloudflared 下载失败 | 网络被拦截 → 手动下载 exe 放入项目 `tools/`（README 常见问题有直链） |

## 安全边界（默认只读）

- 对爱思办公仅做**只读**调用（唯一例外：手机发消息 `session/prompt`，需配对令牌 + 限速 + 可关闭）。
- agnesd 密钥只在电脑内存；SMTP 授权码只存本机 `config.json`，永不回传前端。
- 配置向导仅限 `127.0.0.1` 访问；公网流量经 Cloudflare 加密隧道中转。
