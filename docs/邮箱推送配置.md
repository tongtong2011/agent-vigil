# 邮箱推送配置指引（获取 SMTP 授权码）

> 适用版本：V2 及以上 · 内容与 `lib/mailer.js` 注释及配置向导实现核对（2026-10-11）

在配置向导第 2 步（或直接编辑 `config.json` 的 `mailer` 段）填写。**授权码不是邮箱登录密码**：

| 邮箱 | 开通路径 |
| --- | --- |
| **QQ 邮箱** | 网页版 → 设置 → 账号 → 「POP3/IMAP/SMTP…服务」→ 开启「SMTP 服务」→ 按提示发短信 → 生成 16 位授权码 |
| **163 / 126** | 网页版 → 设置 → POP3/SMTP/IMAP → 开启「IMAP/SMTP 服务」→ 弹窗设置「授权码」（会发送短信确认） |
| **Gmail** | 需先开启两步验证 → Google 账号 → 安全 → 「应用专用密码」生成 16 位密码 |

## 服务器与端口

QQ `smtp.qq.com:465`、163 `smtp.163.com:465`、126 `smtp.126.com:465`、Gmail `smtp.gmail.com:465`（均 SSL）；向导里选服务商会自动填。

## 使用要点

- 收件邮箱填**自己的邮箱**即可（自己发给自己）；支持**逗号分隔多个地址**群发（中英文逗号均可，自动去空去重，单个地址被对方服务器拒收不影响其余收件人）
- 填完先点向导里的「**发送测试邮件**」验证，成功后保存即生效
- **多家发件邮箱切换（发件配置档案）**：配置好并测试成功后点「💾 保存当前为档案」命名保存；之后换服务商整段重填，或从「📁 已保存的发件配置」下拉一键应用。「↺ 重置发件配置」只清发件配置，**收件邮箱与已保存档案不受影响**。已存 ≥2 份档案时，当前配置连续 2 次发送失败会自动切换下一份并立即重试
- **个别非标服务商（如 2925.com）**：要求发件地址必须是授权身份之一（通常是手机号别名），登录邮箱发不出去。向导「高级 → 发件地址」填入提示中列出的身份即可（测试邮件失败时会自动给出可填的地址）

## 技术背景：为什么不用 nodemailer

实测部分非标 SMTP 服务器（如 2925.com 的 .NET 自研实现）在 AUTH 成功后重置会话状态，MAIL FROM 被挂起，nodemailer 会报 `Connection closed unexpectedly`。项目自研的轻量客户端（`lib/smtp.js`）在 AUTH 后自动重发 EHLO，已实测打通（详见 CHANGELOG V2 修复记录）。

## 安全

授权码只存在你自己电脑的 `config.json`（该文件已被 .gitignore 排除，不会进入版本库），随时可在邮箱设置里撤销。向导与远程配置页都只显示掩码，凭据永不回传前端。
