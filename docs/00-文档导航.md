## 六、缺失与计划中的文档（缺口清单）

| 计划文档 | 类型 | 优先级 | 说明 |
|---|---|---|---|
| LICENSE | 开源必备 | 高 | 开源发布前必须有授权协议 |
| 用户使用手册 | 用户文档 | 高 | 面向最终用户（非部署者）：手机端操作、告警使用、FAQ——商业化公开 💼 |
| API 接口文档 | 技术实现 | 中 | localApi / remoteApi / setupApi / ws 消息格式——开源公开 🌍 |
| 安全与隐私说明 | 安全 | 中 | 数据流向、凭据存储边界（授权码/令牌永不回传）、公网暴露面——开源公开 🌍 |
| 贡献指南 CONTRIBUTING | 开源必备 | 中 | 开源后接收 PR 前必须有 |
| 部署运维手册 | 运维 | 低 | 服务自启、日志、升级流程（README 部分覆盖，独立成文更好） |

## 七、维护规则

1. **新增文档必须登记**本页对应分类，写清类型/定位/公开级别
2. 文档改名/移动：同步修本页链接（相对路径）
3. 每次版本打包：检查「五」的资产表 + 「六」的缺口清单是否要更新
4. 开源/商业化发布前：按本页公开级别列直接筛选——🌍 全收、💼 按说明裁剪、🔒 排除
