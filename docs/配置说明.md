# 配置说明（config.json 全参考）

> 适用版本：V3.x 及以上 · 与 `lib/config.js` 默认值逐一核对（2026-10-11）
> 修改 `config.json` 后重启桥接服务生效；邮箱/隧道/告警等多数配置建议走配置向导（保存即热生效，无需重启）。

## 监听与轮询

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `listenHost` | `0.0.0.0` | 监听地址 |
| `port` | `8787` | 桥接服务端口（被占用时启动会明确报错退出） |
| `timeoutMs` | `5000` | 网络超时（毫秒） |
| `pollIntervalMs` | `3000` | 变化检测轮询间隔（毫秒） |

## 数据源（acp）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `acp.autoDiscover` | `true` | 自动发现 agnesd 端口并从进程内存读取密钥（推荐保持开启） |
| `acp.port` / `acp.secret` | `0` / `''` | 自动发现失败时手动指定。注意：agnesd 重启后端口与密钥都会变，手动指定仅适合临时排查 |
| `official.*` | 占位符 | HTTP 直连配置，**当前版本未使用**（预留） |

## 公网隧道（tunnel）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `tunnel.enabled` | `true` | 启动时拉起 cloudflared；未安装时自动从 Cloudflare 官方下载到 `tools/`（约 18MB，仅一次），失败才降级纯局域网 |
| `tunnel.mode` | `quick` | `quick` = trycloudflare 快速隧道（零配置，地址随重启变化）；`named` = 命名隧道（固定域名） |
| `tunnel.hostname` | `''` | named 模式的看板访问域名 |
| `tunnel.tunnelName` | `agnes-board` | Cloudflare 账号内隧道名（重名自动加后缀） |
| `tunnel.tunnelToken` | `''` | named 模式运行令牌（向导初始化成功后自动写入；仅存本机，绝不回传前端） |
| `tunnel.cloudflaredPath` | `''` | 留空 = 依次找项目 `tools/` → PATH |

## 配对与消息（pair / messages）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `pair.codeTtlMinutes` | `15` | 配对码有效期（分钟），范围 5~120。**码在有效期内可重复使用**（多设备可先后配对），过期自动作废并推送新码 |
| `messages.enabled` | `true` | 手机发消息开关（等价于电脑端输入框发消息；限速每分钟 10 条）。`false` = 回归纯只读看板 |

## 邮箱推送（mailer）

| 字段 | 说明 |
| --- | --- |
| `smtpHost` / `smtpPort` / `smtpSecure` | SMTP 服务器；465 = SSL（`smtpSecure: true`），587 = STARTTLS（置 `false`） |
| `user` / `pass` | 发件邮箱与 **SMTP 授权码**（不是登录密码） |
| `to` | 收件邮箱；支持逗号分隔多个（中英文逗号均可，自动去空去重；单个地址被拒收不影响其余）。可填自己发给自己 |
| `from` | 可选发件地址别名（个别非标服务商如 2925.com 要求填授权身份） |
| `saved` | 已保存的发件配置档案数组（含授权码，仅存本机）。≥2 份时当前配置连续 2 次发送失败自动故障转移 |
| `toHistory` | 收件邮箱历史（远程配置页下拉快选，最多 10 条） |
| （整段留空） | = 关闭邮箱推送，所有调用安静返回，不影响服务 |

## 企业微信推送（wecom，可选）

`corpId` / `corpSecret` / `agentId` / `toUser`（默认 `@all`）。留空 = 关闭。接收端：微信 → 通用 → 辅助功能 → 微工作台。

## 任务告警（alerts，V3）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `digestEnabled` | `false` | 「任务汇总」总开关（定时把被追踪任务汇总成表格邮件）。向导第 4 步可配 |
| `digestIntervalMinutes` | `60` | 汇总间隔（分钟），10~240 |
| `digestTitle` | `任务汇总邮件` | 汇总邮件标题 |
| `alertEnabled` | — | 「单任务报警」总开关（被追踪任务出现异常/待确认时立即发信）。向导第 4 步可配 |
| `alertPrefix` | `单任务报警-` | 报警邮件标题前缀（标题 = 前缀 + 任务名） |
| `watchlist` | `[]` | 追踪清单的**服务端同步副本**：源头在手机端 localStorage，变化时自动写回本文件，桥接重启从这里恢复 |

## 其他

| 字段 | 说明 |
| --- | --- |
| `setup.done` | 配置向导是否已完成（完成后启动不再弹首次提示） |

## 数据来源与访问边界（ACP 模式）

- 桥接通过爱思办公内置本地 AI 后端 `agnesd`（goose 框架）读取：`session/list` 拉任务（会话）列表，`session/load` 重放会话历史聚合为对话内容；WebSocket 长连接实时订阅变化。
- 端口从爱思办公日志自动发现；密钥由 `lib/get-agnes-secret.ps1` 从 agnesd 进程内存读取（随机生成、不落盘），只存电脑端内存，绝不下发手机端。
- **默认只读**：仅调用 `initialize` / `session/list` / `session/load` 三个读方法。唯一写方法例外是手机发消息（`session/prompt`），须配对设备令牌触发、限速、可在配置中关闭。
